## 0.2.2 - 2026-11-19

Commit `08b8e169dc26`; release record `pub:sha2-256:qsyei7ddkgqfl6nwfdouzhjevoqmxjofijgitjotbxn5d7qg7zxa`.

### Added
- Steps for a refusal's class and fields, a result key's includes and matches, an answer header's includes, stderr is empty, lines not matched, stand-in runs not matched or in order, a fake service's header and body together, a request without a header or every request with one; pubtest.http.url for a listening server in Python; TypeScript declarations for the npm package
